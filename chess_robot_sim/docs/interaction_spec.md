# Interaction Spec

本文件由成员 A 维护。

## CLI Commands

| 命令 | 含义 |
|---|---|
| `A1 B1` | 从 `A1` 移动到 `B1` |
| `reset` | 清盘 / 复位 |
| `hand_on` | 模拟人手进入安全区 |
| `hand_off` | 模拟人手离开安全区 |

## GUI Minimum Version

GUI 最小版本只需要：

1. 起点输入；
2. 终点输入；
3. submit 按钮；
4. reset 按钮；
5. hand_on / hand_off 按钮。

不要求一开始做完整棋盘点击界面。
